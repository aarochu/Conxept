# web (Lane C, Angular)

Angular 22 app (standalone components, signals, zoneless). It talks to the gateway with the Connect
protocol through `@connectrpc/connect-web`, using the TypeScript client generated by `protoc-gen-es` into
`web/src/gen/` (not committed; run `make gen`). Math is rendered with KaTeX from the `*_latex` fields.

| Route | Page | Shows |
| --- | --- | --- |
| `/` | `pages/class-list.ts` | Classes; Seed synthetic class (60 students); Process with a live progress bar |
| `/class/:id` | `pages/class-dashboard.ts` | Heatmap (problems × steps, first-wrong count / reached, one colour ramp, number always shown), clusters by count, Analyze with a live tool log and the brief |
| `/class/:id/cluster/:key` | `pages/cluster.ts` | Name, description, fix hint, examples, Generate practice (3) with answer keys and verification routes |
| `/class/:id/submission/:sid` | `pages/submission.ts` | The student's steps, first wrong step highlighted next to the expected value |
| `/try` | `pages/try.ts` | Pick a problem, type steps, diagnosis updates as you type |
| `/class/:id/evaluation` | `pages/evaluation.ts` | False alarms, step / label / held-out accuracy, per-label table |

Shared: `api.ts` (one Connect client, cached problem and catalog lookups, readable error messages),
`latex.ts` (KaTeX directive), `pages/derivation.ts` (derivation view used by Submission and Try).

## Run

```bash
make web-build   # production build into web/dist/web/browser; `make gateway` serves it on :8080
make web         # dev server on :4200; proxy.conf.json sends /misconception.v1.GatewayService to :8080
```

## Notes

- A misconception can occur at several (family, step) places (for example, dropped u(t)), so `GetClusters` can
  return the same key more than once. The dashboard lists each place; the cluster page merges them.
- Unclassified clusters are shown as **Other** and never given a cause.
- Mobile layout is a non-goal (spec §1); at phone width the page still has no horizontal scroll, and the heatmap
  scrolls inside its card.
