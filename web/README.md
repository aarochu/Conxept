# web (Lane C, Angular)

Standalone-component Angular app. Connect client generated by `protoc-gen-es` into `web/src/gen/`
(not committed), called via `@connectrpc/connect-web`. Dev proxy sends
`/misconception.v1.GatewayService/` to `http://localhost:8080`.

Routes (spec §6.4): `/`, `/class/:id`, `/class/:id/cluster/:key`, `/class/:id/submission/:sid`,
`/try`, `/class/:id/evaluation`. Math via KaTeX.
